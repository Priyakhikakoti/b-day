# Arunabh, level up

> **Level Up: Boyfriend Edition** — A personalized, romantic interactive mini-game and digital keepsake.

## Features
- **5 Interactive Levels**: Personalized relationship trivia with memories and dynamic image crops.
- **Final Boss Trial**: 3-phase boyfriend test with health gauge.
- **Best Boyfriend Award**: An official digital achievement plaque with couple and character portraits.
- **Scratch-Off Love Coupon**: Interactive metallic gold scratch card for a real-life reward.
- **Love Letter Keepsake**: Virtual envelope with wax seal, typewriter letter reveal, and confetti.
- **Save Keepsake Card**: Direct high-resolution certificate generation for camera rolls.
- **Gentle Ambient Music Box BGM**: Synthesized romantic lullaby via Web Audio API.
